# Project documentation

KisdeTweaks targets Minecraft Java 1.12.2 and LiteLoader, with MaLiLib required for its configuration UI and hotkeys. The code is derived from LiteTweaker under LGPL-3.0; see the root `LICENSE` for terms and the upstream notice.

- `features.md` — implementation and compatibility status for each feature.
- `build.md` — build setup and verified artifact details.
- `compatibility.md` — supported loader and optional integrations.
